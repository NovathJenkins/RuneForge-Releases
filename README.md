# RuneForge — official downloads

An OSRS DPS calculator and gear optimizer.

Download the Windows x64 ZIP from [Releases](https://github.com/NovathJenkins/RuneForge-Releases/releases). Extract the whole folder and run RuneForge.exe. This unsigned build has no automatic installer: its update check links to a new ZIP. Keep workspace backups.
